# MRFoundry paper evidence

Inspect the retained evidence behind the MRFoundry toolbox paper:

- [Demonstration archive](evidence/README.md): original sequence-design, coarse-simulation, reconstruction and diffusion scripts, saved reports, input identities and integrity hashes.
- [Historical evaluation record](evidence/evaluation/HISTORICAL-EXECUTION.md): frozen execution provenance and the scope of the released evaluation materials.
- [Input sources and licenses](evidence/INPUTS-AND-LICENSES.md): exact public data URLs and checksums; raw acquired datasets are not duplicated.

These are inspectable historical records. The original demonstration scripts retain workspace-specific packaging dependencies and have not been newly tested as portable scientific reproductions. The existing numerical outcomes are unchanged. No new experiments or regrading were performed for this release.

Author-generated code and documentation use the repository’s [MIT license](../LICENSE); upstream software and data keep their own licenses. Benchmark tasks and the frozen public results are maintained in [MRI Agent Bench](https://github.com/KeWang0622/MRIAgentBench).
