# MRFoundry visual assets

MRFoundry combines a blue-and-ivory MRI mascot with a two-tone wordmark.

Use `mrfoundry-logo-light.svg` or `mrfoundry-logo-dark.svg` for the full name,
`mrfoundry-mark.svg` for the icon, and `mri-mascot.png` for the full-size transparent
character. PNG lockups, square icon sizes, wordmark-only SVGs and a favicon
are also included.

See [BRAND.md](BRAND.md) for formats, colors and usage, and
[mascot-provenance.json](mascot-provenance.json) for source hashes and generation
prompts. The mascot is decorative artwork made with OpenAI image generation;
it is not a patient image or a scientific simulation.
