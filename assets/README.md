# MRFoundry visual assets

The scanner identity was revised on **2026-10-29** to clearly depict a long-bore
MRI system. Its deep magnet barrel, visible patient tunnel and aligned table
replace the previous shallow scanner silhouette. The original blue/cream mascot
personality and outlined two-tone wordmark are retained.

The README uses `mrfoundry-logo-light.svg` / `mrfoundry-logo-dark.svg` with
`mri-mascot-transparent.png`. `mri-mascot.png` is the dark-background presentation
variant; `mri-agent-transparent.png` is the illustrated scanner-and-laptop asset
for workflow explanations. `logo.svg` remains a compatible default-symbol alias.

See [BRAND.md](BRAND.md) for all variants, colors and usage. Exact image-edit
prompts and the native SVG design specification are saved alongside the assets.
The PNGs were edited using the built-in OpenAI image generation tool. The compact
flat vector emblem was restored on 2026-10-30 from the two-tone identity, because it
reads more cleanly beside the wordmark than the three-quarter emblem. These are decorative illustrations,
not scanner photographs, patient data or scientific simulations. Preserve their
aspect ratios and the substantial magnet depth when reusing them.
