# MRFoundry visual assets

The current identity uses the approved **2026-11-03 blue-and-ivory MRI mascot**
with the original outlined MRFoundry lettering. The README displays one combined
light/dark lockup; it does not add a second mascot beside it.

Use `mrfoundry-logo-light.svg` or `mrfoundry-logo-dark.svg` for the full name,
`mrfoundry-mark.svg` for the icon, and `mri-mascot.png` for the full-size transparent
character. PNG lockups, square icon sizes and a favicon are also included. The
wordmark-only SVGs remain unchanged.

See [BRAND.md](BRAND.md) for variants and compatibility aliases, and
[mascot-provenance.json](mascot-provenance.json) for source hashes. The current
prompts are `mascot-generation-prompt.txt` and `mascot-alpha-prompt.txt`; older
prompt files are marked historical. The artwork is decorative and AI-generated,
not a patient image or a scientific simulation.
