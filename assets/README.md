# MRFoundry visual assets

`mri-mascot.png` is the MRI scanner mascot used on the research talk cover. It was generated with the built-in OpenAI imagegen tool on 2026-09-22 and selected by the repository owner. The exact generation prompt is in `mri-mascot-prompt.txt`.

This is decorative AI-generated artwork, not a scanner photograph, patient image, or scientific simulation. No patient data or third-party reference image was used in its generation. Keep the original proportions when displaying it.

The README uses a native-text **MRFoundry** heading beside the transparent mascot, so the name stays readable in light and dark themes. The retired raster wordmarks are no longer shipped. `logo.svg` is an optional compact MRI icon; its accessible name is MRFoundry.

`mri-mascot-transparent.png` is a transparent cutout of that mascot, edited with OpenAI imagegen on 2026-09-22 for the compact README header. It removes the background and floor while preserving the scanner. The edit prompt is in `mri-mascot-transparent-prompt.txt`.
