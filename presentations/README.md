# MRFoundry: MRI research with AI agents

[View the interactive presentation online](https://kewang0622.github.io/slides/mrfoundry/).

The 25-slide deck introduces research agents, MRI skills and tools, and interactive MRI examples. It includes chapter navigation, speaker notes, live simulations, contact details, and an interactive self-improvement workflow: retrieve, execute, evaluate, update, then reuse and verify.

## Viewing

Use the arrow keys or on-screen controls to move between slides. The top chapter bar jumps between sections; **N** toggles speaker notes.

The [presentation source](https://github.com/KeWang0622/KeWang0622.github.io/tree/master/slides/mrfoundry) is available in the website repository.

The deck uses the [MRFoundry visual identity](../assets/BRAND.md): a two-tone wordmark and blue-and-ivory MRI mascot.

The MRI mascot is decorative AI-generated artwork. Interactive demonstrations use analytic phantoms. The research-memory page explains a general feedback process, scoped evidence and personal research preferences. No patient scans are included.
